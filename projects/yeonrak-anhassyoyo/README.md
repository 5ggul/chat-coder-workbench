# 연락안했어요

실제로 연락하지 않고도 보내고 싶은 말을 앱 안에서 끝낼 수 있게 하는 모바일 앱 프로토타입입니다.

## v1 기능

- 연락 D-DAY와 실시간 카운터
- 상대 별명별 연속 기록
- 가짜 메시지 전송
- 전송 후 즉시 삭제 / 24시간 봉인 / 7일 봉인
- 봉인함과 보상형 광고 기반 조기 열기
- 90초 긴급 위기모드 (광고 없음)
- 30일 기본 그래프 / 광고로 90일 그래프 7일 해금
- 감정 비중 분석
- 주간 리포트 / 광고로 상세 리포트 해금
- 주간 / 시즌 / 연속 기록 / 새벽 방어 랭킹
- 레벨과 배지
- PWA 오프라인 기본 지원
- 네이티브 AdMob rewarded adapter 계약 포함

## 광고 원칙

핵심 기능은 광고 없이 사용합니다. 보상형 광고는 사용자가 직접 선택한 부가 기능에만 사용합니다.

- 오늘의 심층 분석
- 90일 장기 그래프
- 상세 주간 리포트
- 봉인 메시지 조기 열기

브라우저 프로토타입에서는 `ads.js`가 보상 성공을 시뮬레이션합니다. 네이티브 앱에서는 `YEONRAK_NATIVE_ADS.showRewarded()`를 실제 AdMob adapter로 주입합니다. `native-rewarded-adapter.ts`는 `react-native-google-mobile-ads` 기반 production adapter 예시입니다. 실제 광고 송출에는 AdMob 앱/광고단위 ID와 네이티브 빌드 설정이 필요합니다.

## 개인정보 원칙

- 실제 연락처를 읽지 않음
- 상대는 별명으로만 등록
- 메시지 원문은 서버로 보내지 않음
- 봉인을 선택한 메시지만 기기 로컬 저장소에 저장
- 향후 랭킹 서버에는 익명 사용자 ID, 점수, 연속 기록 등 최소값만 전달
